# 422-foodweb — 숲을 잇다

태블릿 가로 화면용 먹이그물 웹게임. 먹는 동물을 고른 뒤 먹이를 선택해 연결하고, 선을 눌러 양·먹이·연결을 바로 수정합니다. 직접 선을 잇고 먹이를 고르는 튜토리얼, 개체 수에 따라 늘고 줄어드는 그림, 개체 게이지, 연속 3개 위기가 있습니다.

정적 HTML/CSS/JavaScript와 자체 WebP 그림만 사용합니다. 계정·랭킹·서버 저장·외부 라이브러리가 없습니다. 진행은 이 기기의 localStorage에 저장하며, 새로 열면 일시정지 상태로 이어집니다. 타이틀의 설정에서 전체 초기화를 누르고 “초기화합니다”를 입력한 뒤 최종 확인해야 진행·점수·튜토리얼 기록을 지웁니다. 취소하면 기록을 유지합니다. 브라우저 저장소를 비워도 진행이 지워집니다.

웹 서버로 폴더를 열거나 GitHub Pages의 main 브랜치 루트에 배포합니다. 각 환경 그림은 처음 이동할 때 불러오며, 같은 환경에서 플레이하는 동안 추가 서버 요청은 없습니다. 튜토리얼은 한 번에 한 가지 동작과 그 이유를 한 문장씩 짧게 안내하고 다음에 누를 생물·선·버튼을 강조합니다. 실제로 조작해야 다음 안내로 넘어갑니다. 첫 연습에서는 토끼→여우 화살표를 함께 만들고, 토끼의 먹이는 학생이 직접 골라 연결합니다. 여러 선으로 먹이를 나누거나 잘못된 선을 고칠 수 있으며, 먹이와 생산량을 맞춘 그물 그대로 게임을 시작합니다. 조작법은 언제든 열 수 있습니다.

이 게임은 먹이 공급·소비에 따른 균형 변화를 학습하기 위한 단순화된 모형입니다. 표시된 화살표는 교과서처럼 먹히는 생물 → 먹는 생물로, 먹이와 에너지가 전달되는 방향입니다. 연결 조작은 먹는 동물을 먼저 고르고 먹이를 선택하는 방식이며 튜토리얼에서 구분해 안내합니다. 개체 게이지는 실제 개체 수 대신 0–100 지수이고, 생물 그림 하나는 지수 약 10을 나타냅니다.

## 먹이와 생산량 규칙

모든 소비자는 기본 먹이 2칸에 먹히는 양을 더한 만큼 먹어야 개체 수가 유지됩니다. 예를 들어 토끼가 1칸 먹히면 먹이 3칸이 필요합니다. 화면에 현재 먹이/필요 먹이를 표시합니다.

생산자를 누르면 생산량을 3–8칸으로 조절할 수 있습니다. 소비가 생산보다 많으면 식물 개체가 줄고, 생산량을 늘리면 식물 그림이 점차 늘어납니다.

선 편집의 +/−는 적용 전의 양을 고릅니다. 확인을 눌러 적용하며, 0칸으로 확인하면 연결을 제거합니다. 연결 끊기는 별도의 버튼으로도 가능합니다. 먹이 종류 바꾸기는 실제로 다른 먹이로 연결을 바꾸는 별도 기능입니다. 편집창의 ×는 양 변경을 취소합니다.

세 라운드를 모두 해결하면 사라졌던 생물이 돌아오고 기본 먹이도 연결됩니다. 완료 점수와 기존 먹이그물은 유지되며, 이전에 완료한 저장 기록에도 복귀가 적용됩니다. 자유 탐험 중 편집한 연결은 다시 열어도 유지됩니다.

## 숲·바다·초원 탐험

환경마다 세 문제씩 총 아홉 문제를 풀며, 완료하면 다음 환경이 열립니다. 다음 문제·환경으로 이동하면 자동으로 일시정지합니다. 먹이선과 생산량을 조절한 뒤 시작을 눌러 균형을 확인합니다. 왼쪽 위 환경 지도에서 완료한 곳을 다시 찾아가 자유 탐험할 수 있습니다. 환경별 먹이그물과 진행은 기기에 따로 저장됩니다. 예전 숲 완주 기록도 유지됩니다. 자세한 환경 구성과 참고 자료는 [HABITATS.md](HABITATS.md)를 확인하세요.

플레이 화면의 다시하기는 현재 문제의 시작 상태로 먹이선·개체 수·생산량·씨앗과 이 문제에서 얻은 점수·시간만 되돌립니다. 이전 문제 및 다른 환경 기록은 유지하며, 다시하기 후에는 일시정지 상태입니다. 시작 상태는 기기에 함께 저장됩니다. 예전 버전 기록은 최초로 불러온 상태를 시작 상태로 사용합니다. 전체 기록 삭제는 타이틀의 설정 → 전체 초기화에서 별도로 진행합니다.
