# 422-foodweb — 숲을 잇다

태블릿 가로 화면용 먹이그물 웹게임. 먹는 동물에서 먹이로 연결하고, 선을 눌러 양·먹이·연결을 바로 수정합니다. 튜토리얼, 개체 수에 따라 늘고 줄어드는 그림, 개체 게이지, 연속 3개 위기가 있습니다.

정적 HTML/CSS/JavaScript와 자체 WebP 그림만 사용합니다. 계정·랭킹·서버 저장·외부 라이브러리가 없습니다. 진행은 이 기기의 localStorage에 저장하며, 새로 열면 일시정지 상태로 이어집니다. 초기화 버튼을 누르고 “초기화합니다”를 입력한 뒤 최종 확인해야 진행·점수·튜토리얼 기록을 지웁니다. 취소하면 기록을 유지합니다. 브라우저 저장소를 비워도 진행이 지워집니다.

웹 서버로 폴더를 열거나 GitHub Pages의 main 브랜치 루트에 배포합니다. 정적 파일 최초 로딩 이후 게임 중 서버 요청은 없습니다. 페이지를 처음부터 다시 시작해도 조작법은 언제든 열 수 있습니다.

이 게임은 먹이 공급·소비에 따른 균형 변화를 학습하기 위한 단순화된 모형입니다. 표시된 화살표는 “먹는다” 방향(먹는 동물 → 먹이)이며, 교과서의 에너지 전달 화살표와 구분해 안내합니다. 개체 게이지는 실제 개체 수 대신 0–100 지수이고, 생물 그림 하나는 지수 약 10을 나타냅니다.

## 먹이와 생산량 규칙

모든 소비자는 기본 먹이 2칸에 먹히는 양을 더한 만큼 먹어야 개체 수가 유지됩니다. 예를 들어 토끼가 1칸 먹히면 먹이 3칸이 필요합니다. 화면에 현재 먹이/필요 먹이를 표시합니다.

생산자를 누르면 생산량을 3–8칸으로 조절할 수 있습니다. 소비가 생산보다 많으면 식물 개체가 줄고, 생산량을 늘리면 식물 그림이 점차 늘어납니다.

선 편집의 +/−는 적용 전의 양을 고릅니다. 확인을 눌러 적용하며, 0칸으로 확인하면 연결을 제거합니다. 연결 끊기는 별도의 버튼으로도 가능합니다. 먹이 종류 바꾸기는 실제로 다른 먹이로 연결을 바꾸는 별도 기능입니다. 편집창의 ×는 양 변경을 취소합니다.

세 라운드를 모두 해결하면 사라졌던 생물이 돌아오고 기본 먹이도 연결됩니다. 완료 점수와 기존 먹이그물은 유지되며, 이전에 완료한 저장 기록에도 복귀가 적용됩니다. 자유 탐험 중 편집한 연결은 다시 열어도 유지됩니다.
