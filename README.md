# 422-foodweb — 숲을 잇다

태블릿 가로 화면용 먹이그물 웹게임. 먹는 동물에서 먹이로 연결하고, 선을 눌러 양·먹이·연결을 바로 수정합니다. 튜토리얼, 개체 수에 따라 늘고 줄어드는 그림, 개체 게이지, 연속 3개 위기가 있습니다.

정적 HTML/CSS/JavaScript와 자체 WebP 그림만 사용합니다. 계정·랭킹·서버 저장·외부 라이브러리가 없습니다. 진행은 이 기기의 localStorage에 저장하며, 새로 열면 일시정지 상태로 이어집니다. 브라우저 저장소를 비우면 진행도 지워집니다.

웹 서버로 폴더를 열거나 GitHub Pages의 main 브랜치 루트에 배포합니다. 정적 파일 최초 로딩 이후 게임 중 서버 요청은 없습니다. 페이지를 처음부터 다시 시작해도 조작법은 언제든 열 수 있습니다.

이 게임은 먹이 공급·소비에 따른 균형 변화를 학습하기 위한 단순화된 모형입니다. 표시된 화살표는 “먹는다” 방향(먹는 동물 → 먹이)이며, 교과서의 에너지 전달 화살표와 구분해 안내합니다. 개체 게이지는 실제 개체 수 대신 0–100 지수이고, 생물 그림 하나는 지수 약 10을 나타냅니다.
